# Gran-Secreto

Objetivo del proyecto: Desarrollar una página web que permita descubrir lugares interesantes y poco conocidos de Medellín, ofreciendo una experiencia visual, sencilla e interactiva.

HU-01. Página principal y navegación

Historia de usuario:
Como visitante, quiero encontrar una página principal atractiva y un menú de navegación sencillo para conocer el propósito de GRAN SECRETO y acceder fácilmente a sus diferentes secciones.

Criterios de aceptación:

1. La página debe tener un encabezado con el nombre y logo de GRAN SECRETO.
2. Debe existir un menú de navegación.
3. Debe incluir una sección de bienvenida con el eslogan del proyecto.
4. El menú debe permitir acceder a las secciones principales.
5. La navegación debe funcionar correctamente.

Prioridad: Alta — Must have.

HU-02. Exploración de lugares

Historia de usuario:

Como visitante, quiero explorar diferentes lugares de Medellín mediante fotografías y descripciones para descubrir nuevos sitios que pueda visitar.
 
Criterios de aceptación:

1. Se deben mostrar al menos 12 lugares.
2. Cada lugar debe tener una fotografía, nombre y descripción breve.
3. Los lugares deben organizarse en tarjetas visuales.
4. Las tarjetas deben permitir acceder a más información.
5. Las imágenes deben corresponder a los lugares publicados.


HU-03. Categorías de lugares

Historia de usuario:

Como visitante, quiero encontrar lugares organizados por categorías para descubrir opciones según mis intereses.

Criterios de aceptación:
   
1. Deben existir categorías como gastronomía, naturaleza, cafés y miradores.
2. Cada lugar debe pertenecer a una categoría.
3. Las categorías deben ser fáciles de identificar.
4. El usuario debe poder seleccionar una categoría.
5. Debe existir una opción para visualizar todos los lugares.
6. Prioridad: Alta — Must have.

HU-04. Información detallada de los lugares

Historia de usuario:

Como visitante, quiero consultar información detallada de cada lugar para conocer sus características antes de decidir visitarlo.
   
Criterios de aceptación:
   
1. Cada lugar debe mostrar una descripción ampliada.
2. Debe incluir su dirección o ubicación.
3. Debe mostrar su categoría.
4. Debe permitir regresar al catálogo de lugares.
5. Cuando sea posible, debe incluir un enlace externo para consultar cómo llegar.

HU-05. Buscador de lugares

Historia de usuario:

Como visitante, quiero buscar lugares por su nombre para encontrarlos rápidamente sin tener que revisar todo el catálogo.

Criterios de aceptación:
1. Debe existir una barra de búsqueda.
2. El usuario debe poder escribir el nombre de un lugar.
3. Los resultados deben actualizarse según la búsqueda.
4. La búsqueda no debe distinguir entre mayúsculas y minúsculas.
5. Si no hay resultados, debe aparecer un mensaje informativo.

HU-06. Lugares favoritos

Historia de usuario:

Como visitante, quiero guardar mis lugares favoritos para encontrarlos fácilmente cuando vuelva a ingresar a la página.

Criterios de aceptación:

1. Cada tarjeta debe tener un botón para agregar a favoritos.
2. El botón debe mostrar visualmente cuando un lugar está guardado.
3. Debe existir una sección para consultar los favoritos.
4. El usuario debe poder eliminar lugares de favoritos.
5. Los favoritos deben permanecer guardados mediante LocalStorage.
